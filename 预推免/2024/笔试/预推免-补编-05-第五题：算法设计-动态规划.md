## 第五题：算法设计-动态规划

### 涉及知识点

#### 1. 动态规划基本概念

**定义**：通过把原问题分解为子问题，存储子问题的解以避免重复计算，自底向上求解的算法设计方法。

**适用条件**：

1. **最优子结构**：问题的最优解包含子问题的最优解
2. **重叠子问题**：递归过程中多次求解相同的子问题

**与分治法的区别**：

- 分治法：子问题独立，不重叠（如归并排序）
- 动态规划：子问题重叠，需要记忆化

#### 2. 动态规划设计步骤

1. **定义状态**：dp\[i\] 或 dp\[i\]\[j\] 表示什么
2. **找状态转移方程**：dp\[i\] 如何从之前的状态推导
3. **确定初始条件**：dp\[0\] 或边界情况
4. **确定计算顺序**：通常是从小到大
5. **确定答案位置**：通常是 dp\[n\]

#### 3. 经典动态规划问题

##### 3.1 线性DP

**斐波那契数列**：

```text
dp[i] = dp[i-1] + dp[i-2]
```

**最长递增子序列（LIS）**：

```text
dp[i] = max(dp[j] + 1) for all j < i and arr[j] < arr[i]
```

时间O(n²)，可优化到O(nlogn)

**最大子数组和（Kadane算法）**：

```text
dp[i] = max(dp[i-1] + arr[i], arr[i])
```

**买卖股票最佳时机**：

```text
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])  # 不持有
dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])  # 持有
```

##### 3.2 背包问题

**0-1背包**：

- 物品不可重复选择
- `dp[i][w]`：前i个物品，容量w时的最大价值
- 转移：`dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])`

**完全背包**：

- 物品可重复选择
- 转移：`dp[i][w] = max(dp[i-1][w], dp[i][w-weight[i]] + value[i])`
- 注意是dp\[i\]而非dp\[i-1\]

**多重背包**：每个物品有数量限制

**分组背包**：物品分组，每组最多选一个

##### 3.3 区间DP

**状态定义**：`dp[i][j]` 表示区间 \[i, j\] 的解

**计算顺序**：按区间长度从小到大

```text
for length in range(2, n+1):
    for i in range(n-length+1):
        j = i + length - 1
        # 计算 dp[i][j]
```

**经典问题**：

- 最长回文子序列
- 矩阵链乘法
- 合并石子

##### 3.4 树形DP

**状态定义**：在树节点上定义状态

**计算顺序**：后序遍历（子树→根）

**经典问题**：

- 树的直径
- 打家劫舍III（树上）

##### 3.5 状态压缩DP

**适用场景**：状态集合较小（通常n≤20）

**方法**：用整数的二进制位表示状态

**经典问题**：

- 旅行商问题（TSP）
- 集合覆盖问题

#### 4. 优化技巧

**空间优化**：

- 滚动数组：dp\[i\]只依赖dp\[i-1\]时，用两个一维数组交替
- 一维数组：0-1背包可以从后向前遍历

**时间优化**：

- 单调队列优化：O(n²) → O(n)
- 斜率优化（凸包优化）
- 四边形不等式优化

### 详细解析

#### 解法1：动态规划 O(n²)

**1. 状态定义**：

- `dp[i]`：以 `arr[i]` 结尾的最长递增子序列长度

**2. 状态转移方程**：

```text
dp[i] = max(dp[j] + 1) for all j < i and arr[j] < arr[i]
如果没有这样的j，则 dp[i] = 1
```

**3. 初始条件**：

- `dp[i] = 1`（每个元素自身构成长度为1的序列）

**4. 计算顺序**：

- i 从 0 到 n-1

**5. 答案**：

- `max(dp[i]) for all i`

**代码实现**：

```text
def lengthOfLIS(nums):
    if not nums:
        return 0
    
    n = len(nums)
    dp = [1] * n  # 初始化为1
    
    for i in range(1, n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)

# 测试
arr = [10, 9, 2, 5, 3, 7, 101, 18]
print(lengthOfLIS(arr))  # 输出: 4
```

**复杂度分析**：

- **时间复杂度**：O(n²)，两层循环
- **空间复杂度**：O(n)，dp数组

#### 解法2：二分查找优化 O(nlogn)

**思路**：

- 维护一个数组 `tails`，`tails[i]` 表示长度为 i+1 的递增子序列的最小末尾元素
- 遍历数组，对每个元素：

  - 如果大于 `tails` 中所有元素，追加到末尾
  - 否则，二分查找第一个≥它的位置，替换

**关键观察**：

- `tails` 数组是单调递增的
- 替换操作不改变已有的LIS长度，但为后续元素提供更小的"接口"

**代码实现**：

```text
def lengthOfLIS_optimized(nums):
    if not nums:
        return 0
    
    tails = []
    
    for num in nums:
        # 二分查找第一个 >= num 的位置
        left, right = 0, len(tails)
        while left < right:
            mid = (left + right) // 2
            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid
        
        # left 是插入位置
        if left == len(tails):
            tails.append(num)
        else:
            tails[left] = num
    
    return len(tails)

# 使用Python内置bisect
import bisect

def lengthOfLIS_optimized_v2(nums):
    tails = []
    for num in nums:
        pos = bisect.bisect_left(tails, num)
        if pos == len(tails):
            tails.append(num)
        else:
            tails[pos] = num
    return len(tails)
```

**执行过程**：

```text
数组: [10, 9, 2, 5, 3, 7, 101, 18]

num=10: tails=[], 追加 → tails=[10]
num=9:  tails=[10], 9<10, 替换位置0 → tails=[9]
num=2:  tails=[9], 2<9, 替换位置0 → tails=[2]
num=5:  tails=[2], 5>2, 追加 → tails=[2,5]
num=3:  tails=[2,5], 3>2,3<5, 替换位置1 → tails=[2,3]
num=7:  tails=[2,3], 7>3, 追加 → tails=[2,3,7]
num=101: tails=[2,3,7], 101>7, 追加 → tails=[2,3,7,101]
num=18: tails=[2,3,7,101], 18>7,18<101, 替换位置3 → tails=[2,3,7,18]

答案: len(tails) = 4
```

**复杂度分析**：

- **时间复杂度**：O(nlogn)，n次遍历，每次二分查找O(logn)
- **空间复杂度**：O(n)，tails数组最长为n

**注意**：

- `tails` 数组本身不一定是一个合法的LIS（如最后是\[2,3,7,18\]，不是单调的？不对，\[2,3,7,18\]是单调递增的）
- `tails` 的长度等于LIS的长度
- 如果需要输出具体序列，需要额外记录路径

#### 练习3：编辑距离

点击查看答案
