选择题1 比较排序的复杂度分析

一、知识点讲解

1. 比较排序的下界

在排序过程中，仅通过元素之间的比较来确定相对次序的排序算法称为比较排序。基于决策树模型可以证明：对于n个元素的排序，决策树的高度至少为⌈log₂(n!)⌉，由Stirling公式n!≈(n/e)^n，可得log₂(n!)=Ω(n log n)。因此，任何比较排序算法在最坏情况下都需要Ω(n log n)次比较，这是比较排序的时间复杂度下界。

非比较排序（计数排序、基数排序、桶排序）不依赖元素间比较，可以在线性时间内完成，但它们对数据范围或分布有特殊要求。

2. 常见排序算法复杂度对照

排序算法 最好时间 平均时间 最坏时间 空间复杂度 稳定性
直接插入排序 O(n) O(n²) O(n²) O(1) 稳定
希尔排序 O(n^1.3) O(n log²n) O(n²) O(1) 不稳定
冒泡排序 O(n) O(n²) O(n²) O(1) 稳定
快速排序 O(n log n) O(n log n) O(n²) O(log n) 不稳定
简单选择排序 O(n²) O(n²) O(n²) O(1) 不稳定
堆排序 O(n log n) O(n log n) O(n log n) O(1) 不稳定
归并排序 O(n log n) O(n log n) O(n log n) O(n) 稳定
计数排序 O(n+k) O(n+k) O(n+k) O(n+k) 稳定
基数排序 O(d(n+r)) O(d(n+r)) O(d(n+r)) O(n+r) 稳定

3. 稳定性的含义

稳定性是指：对于序列中两个关键字相等的元素，排序后它们的相对次序保持不变。稳定的排序算法包括插入排序、冒泡排序、归并排序、计数排序、基数排序；不稳定的包括希尔排序、快速排序、选择排序、堆排序。

**【易错提示】**快速排序最坏情况O(n²)出现在每次划分极不均匀时（如已有序数组选首元素为基准）；堆排序的最好、最坏、平均时间均为O(n log n)且空间O(1)，但不稳定；归并排序稳定且时间恒为O(n log n)，但需要O(n)辅助空间。

选择题2 程序的定义

一、知识点讲解

1. 算法的五个重要特性

特性 含义
有穷性 算法必须在执行有穷步之后结束，且每一步都在有穷时间内完成
确定性 算法中每条指令必须有确切含义，不产生二义性；相同输入只能得到相同输出
可行性 算法的每一步都能通过有限次基本运算实现
输入 算法有零个或多个外部输入
输出 算法有一个或多个输出（与输入有特定关系的量）

2. 程序与算法的区别

著名计算机科学家Niklaus Wirth提出公式：程序 = 数据结构 + 算法。算法是解决问题的有限步骤序列，而程序是算法用某种程序设计语言的具体实现。

核心区别在于有穷性：算法必须满足有穷性，但程序不一定要满足有穷性。例如操作系统是一个程序，它一旦启动就持续运行，除非关机，永不终止——这不满足有穷性，但它仍然是合法的程序。程序可以无限循环。

3. 算法设计的要求

正确性、可读性、健壮性（鲁棒性）、高效率与低存储量需求。评价算法效率的主要指标是时间复杂度和空间复杂度。

**【易错提示】**考试常考：算法必须有穷，程序可以无穷。程序=数据结构+算法这一公式也常作为选择题考点。

二、真题回忆与解析

选择题3 蒙特卡洛算法的性质

一、知识点讲解

1. 概率算法（随机化算法）的分类

概率算法允许在执行过程中随机选择下一步计算方向，分为四类：

类型 解的正确性 时间特点 典型应用
数值概率算法 得到近似解，精度随时间提高 时间越长精度越高 数值积分、π的计算
蒙特卡洛算法 能得到一个解，但该解可能不正确 求得正确解的概率依赖于计算时间 判定问题、近似计算
拉斯维加斯算法 不会返回不正确的解，但可能找不到解 时间越长找到解的概率越大 随机化快排、字符串匹配
舍伍德算法 总能求得正确解 消除好坏实例差别，时间平均化 随机化选择排序基准

2. 蒙特卡洛算法的核心性质

蒙特卡洛算法用于求问题的准确解（或精确判定），但不保证所得到的解一定正确。它的关键特征是：算法所用时间越多，得到正确解的概率越大。对于许多问题，蒙特卡洛算法可以通过多次重复执行来将错误概率降到任意小。

蒙特卡洛算法分为偏真（true-biased）和偏假（false-biased）：偏真算法判定为真时一定为真，判定为假时可能出错；偏假算法反之。

3. 与拉斯维加斯算法的关键对比

拉斯维加斯算法：返回的解一定正确，但可能返回“无解”（找不到解）；蒙特卡洛算法：一定返回一个解，但这个解可能错误。一句话记忆——“拉斯维加斯不骗人但可能空手而归，蒙特卡洛一定给答案但可能骗你”。

**【易错提示】**舍伍德算法总能得到正确解，它不是通过提高正确概率工作，而是通过随机化消除最坏情况，使所有实例的期望时间相同。

选择题4 主定理（Master Theorem）

一、知识点讲解

1. 主定理的适用形式

主定理用于求解分治递推式的渐近复杂度。设递推式为：

T(n) = aT(n/b) + f(n), 其中 a≥1, b>1 为常数，f(n) 为正函数

其中a是子问题个数，n/b是子问题规模，f(n)是分解与合并的代价。比较f(n)与n^(log_b a)（记为n^d，其中d=log_b a）的增长阶，分三种情况：

2. 三种情况

情况 条件 结论 直觉含义
情况1 f(n) = O(n^(d-ε)), ε>0 T(n) = Θ(n^d) 子问题代价主导，递归树叶子主导
情况2 f(n) = Θ(n^d · log^k n), k≥0 T(n) = Θ(n^d · log^(k+1) n) 两层代价相当，每层均匀
情况3 f(n) = Ω(n^(d+ε)), ε>0, 且满足正则条件 T(n) = Θ(f(n)) 根节点代价主导，合并主导

其中d = log_b a。情况3的正则条件为：存在常数c<1，使得对充分大的n有 a·f(n/b) ≤ c·f(n)。

3. 常见特例

当f(n) = Θ(n^d)时（即k=0的情况2），T(n) = Θ(n^d log n)。例如归并排序T(n)=2T(n/2)+Θ(n)，d=log₂2=1，f(n)=Θ(n¹)，属于情况2，T(n)=Θ(n log n)。

**【易错提示】**主定理三种情况的记忆口诀：f比n^d小→情况1取n^d；f和n^d同阶→情况2乘log；f比n^d大且正则→情况3取f。注意比较时是多项式意义上的大小（差n^ε）。

二、真题回忆与解析

【题4】已知递推式 T(n)=3T(n/2)+n²，根据主定理，T(n)的渐近复杂度为（ ）。

A. Θ(n^1.58) B. Θ(n²) C. Θ(n² log n) D. Θ(n³)

【答案】B。

解析：a=3, b=2, d=log₂3≈1.58。f(n)=n²=Ω(n^(1.58+ε))，取ε≈0.42。验证正则条件：3f(n/2)=3(n/2)²=3n²/4=0.75n²≤c·n²，取c=0.75<1成立。属于情况3，T(n)=Θ(n²)。

选择题5 分支-限界中减少搜索的函数

一、知识点讲解

1. 分支限界法的基本思想

分支限界法类似于回溯法，也是在解空间树上搜索问题解的算法。但回溯法以深度优先方式搜索，而分支限界法以广度优先或最小耗费（最大收益）优先方式搜索。分支限界法中，每个活节点只有一次机会成为扩展节点：一次性生成其所有子节点，在子节点中计算限界函数值，淘汰不可能导出可行解或最优解的节点，其余加入活节点表，此后从活节点表中选择下一个扩展节点。

2. 约束函数与限界函数

函数类型 作用 适用场景
约束函数 在扩展节点处剪去不满足问题约束条件的子树 回溯法和分支限界法均使用
限界函数（Bound Function） 剪去不可能得到比当前已知最优解更优的子树，从而减少搜索量 分支限界法的核心剪枝手段

分支限界法中，限界函数计算每个活节点的上界（对最大化问题）或下界（对最小化问题），如果该界限不优于当前已找到的最优解，则该节点被剪枝。这就是题目所问的“用什么函数减少搜索”——答案是限界函数。

3. 分支限界法的三种队列方式

队列式（FIFO）分支限界法：按先进先出原则选择下一个扩展节点；栈式（LIFO）分支限界法：按后进先出原则；优先队列式分支限界法：按优先级（限界函数值）选择最有利的节点。

**【易错提示】**注意区分：回溯法中也有约束函数和限界函数，但回溯法用约束函数剪去不合法子树、用限界函数剪去非最优子树；分支限界法主要依赖限界函数来引导搜索方向。题目问“分支-限界用什么函数减少搜索”，标准答案是“限界函数”。

二、真题回忆与解析

【题5】分支-限界法中，用于剪去不可能产生最优解的子树、从而减少搜索空间的函数是（ ）。

A. 约束函数 B. 限界函数 C. 目标函数 D. 代价函数

【答案】B。

解析：限界函数（bound function）通过估计节点子树能达到的最优界限，与当前最优解比较，剪去无希望的子树。约束函数用于剪去不满足约束的子树；目标函数是优化的目标本身。

三、模拟训练题

【模拟5-1】分支限界法搜索解空间树的方式是（ ）。

A. 深度优先 B. 广度优先或最小耗费优先 C. 后序遍历 D. 中序遍历

1. 解空间树的两种基本类型

2. 旅行商问题（TSP）的解空间

旅行商问题要求从某城市出发，经过其余n-1个城市恰好一次后返回起点，使总路程最短。当固定起点城市后，剩余n-1个城市的访问顺序就是一个排列，因此TSP的解空间是一棵排列树，叶节点数为(n-1)!（若不固定起点则为n!）。

**【易错提示】**区分子集树和排列树的关键：问题是否涉及“选取”（子集树2^n）还是“排列/顺序”（排列树n!）。0-1背包是子集树，TSP是排列树。

1. 三种分支限界法对比

2. 优先队列式分支限界法

优先队列式分支限界法按照每个活节点的限界函数值（优先级）来选择下一个扩展节点。对于最小化问题（如TSP求最短路径），优先选择下界最小的节点（小根堆）；对于最大化问题（如背包求最大价值），优先选择上界最大的节点（大根堆）。这种选择方式使搜索朝着最有可能找到最优解的方向推进，从而尽快剪枝。

**【易错提示】**FIFO按排队顺序选节点，LIFO按栈顺序选节点，优先队列按限界函数值（优先级）选节点。题目问“优先队列的节点选择顺序依据”，答案是“限界函数值/优先级”。

选择题8 不能用贪心算法解决的问题

1. 贪心算法的基本要素

贪心算法通过在每一步做出局部最优选择，期望最终得到全局最优解。能用贪心算法求解的问题必须满足两个基本要素：

  • 贪心选择性质：问题的整体最优解可以通过一系列局部最优（贪心）选择来达到，即每一步的贪心选择可以依赖以往的选择但不依赖将来的选择。
  • 最优子结构：问题的最优解包含其子问题的最优解。

2. 贪心算法适用与不适用的典型问题

可以用贪心求解 不能用贪心求解（需DP或其他方法）

最小生成树(Prim/Kruskal) 矩阵连乘问题
多机调度问题（近似） 最长公共子序列(LCS)

3. 0-1背包与分数背包的关键区别

选择题9 最大子段和不能用什么方法解决

一、知识点讲解

1. 最大子段和问题定义

给定n个整数（可能为负数）组成的序列a[1..n]，求该序列形如∑a[i..j]的子段和的最大值。当所有整数均为负数时定义最大子段和为0。

2. 三种经典解法

方法 基本思路 时间复杂度 空间复杂度
暴力枚举法 枚举所有i≤j，计算a[i..j]的和并取最大值 O(n²) O(1)
分治法 将序列分成两半，最大子段和要么在左半、要么在右半、要么跨越中点，分别求解取最大 O(n log n) O(log n)
动态规划(Kadane) 令b[j]=max(b[j-1]+a[j], a[j])，b[j]为以a[j]结尾的最大子段和，答案为max(b[j]) O(n) O(1)

3. 为什么贪心法不适用

在教材分类体系中，最大子段和问题被归为分治法和动态规划的经典例题，而非贪心算法例题。原因在于：简单的贪心策略（如“遇到正数就加、遇到负数就停”）不能保证得到最优解——一个负数后面可能跟着更大的正数，跳过这个负数会错过更优的子段。虽然Kadane算法在形式上带有“贪心”色彩（维护当前和，为负则重置），但它本质上是动态规划思想（以每个位置结尾的最优解），其正确性依赖于DP递推而非贪心选择性质。

因此，在算法设计与分析课程的考试语境中，最大子段和“不能用贪心法解决”是标准答案。

**【易错提示】**最大子段和的三种解法及复杂度是高频考点：枚举O(n²)、分治O(n log n)、DP(Kadane) O(n)。考试问“不能用什么方法”，答案是贪心法。

大题1 堆排序思想、过程与稳定性（5分）

一、知识点讲解

1. 堆的定义

堆是一棵完全二叉树，树中每个节点的值都不大于（或不小于）其左右孩子节点的值。分为：

  • 大顶堆（最大堆）：每个节点的值 ≥ 其孩子的值，根节点为最大值。
  • 小顶堆（最小堆）：每个节点的值 ≤ 其孩子的值，根节点为最小值。

堆通常用一维数组存储。对于下标从0开始的数组，节点i的左孩子下标为2i+1，右孩子为2i+2，父节点为⌊(i-1)/2⌋。

2. 堆排序的基本思想

堆排序利用大顶堆（升序排序）或小顶堆（降序排序）来选择最值，分为两个阶段：

  1. 建堆：将无序数组构建为一个大顶堆。从最后一个非叶节点（下标⌊n/2⌋-1）开始，自底向上依次对每个非叶节点执行“筛选”调整。
  2. 排序：反复将堆顶元素（当前最大值）与堆的最后一个元素交换，然后将剩余元素重新调整为大顶堆，直到堆中只剩一个元素。

3. 筛选法调整堆（Heapify）

对节点i执行筛选：找出节点i与其左右孩子中的最大值，若最大值不是节点i本身，则交换，并对被交换的孩子节点递归执行筛选，直到子树满足堆性质。

4. 复杂度与稳定性

指标 值 说明
建堆时间 O(n) 并非n个节点各O(log n)，而是各层代价之和为O(n)
每次调整 O(log n) 堆高为⌊log₂n⌋
总排序时间 O(n log n) n-1次调整，每次O(log n)
空间复杂度 O(1) 原地排序
稳定性 不稳定 筛选过程中相等元素可能发生非相邻交换

**【易错提示】**堆排序不稳定的原因：在筛选调整时，元素可能跨越多个位置与后代交换，相等元素的相对次序可能被改变。考试中要求明确回答“堆排序是不稳定的排序算法”。

二、真题回忆与解析

【题1】（5分）简述堆排序的基本思想。对给定数组 A = [49, 38, 65, 97, 76, 13, 27, 49]，写出堆排序（升序）的全过程，并说明堆排序是否为稳定排序。

解答：

堆排序基本思想：先将待排序数组构建为大顶堆，此时堆顶为全局最大值；然后将堆顶元素与堆尾元素交换，将最大值放到数组末尾，再对前n-1个元素重新调整为大顶堆；重复此过程直到全部有序。

第一步：建堆（初始数组 [49, 38, 65, 97, 76, 13, 27, 49]）

从最后一个非叶节点（下标3，值97）开始，自底向上筛选：

大题2 边权互异无向连通图最小生成树唯一性证明（5分）

一、知识点讲解

1. 最小生成树的定义

设G=(V,E)是一个无向连通带权图，生成树是G的一个极小连通子图，包含V中全部n个顶点和n-1条边。最小生成树（MST）是所有生成树中边权值之和最小的那棵。

2. 最小生成树的两个重要性质

  • 割性质（Cut Property）：对于图的任意一个割(S, V-S)，如果边e是跨越该割的所有边中权值最小的边，则e一定在某棵MST中。当各边权值互异时，该边一定在唯一的MST中。
  • 环性质（Cycle Property）：对于图中任意一个环，如果边e是环上权值最大的边，则e一定不在MST中。当各边权值互异时，环上权值最大的唯一边一定不在MST中。

3. 唯一性条件

当无向连通图中所有边的权值互不相等时，最小生成树是唯一的。这是因为：每一步Kruskal算法或Prim算法选择的边都是唯一确定的（不存在权值相同的边需要打破平局），最终只能得到一棵MST。

**【易错提示】**证明MST唯一性的标准方法是反证法+交换论证：假设存在两棵不同的MST，找到它们不同的边中权值最小的一条，利用割性质或环性质进行边交换，推出其中一棵不是最小的矛盾。

二、真题回忆与解析

【题2】（5分）证明：对各边权值互不相同的无向连通图G，其最小生成树唯一。

证明（反证法 + 交换论证）：

假设G存在两棵不同的最小生成树T₁和T₂，它们的边权和相等，均为W（最小值）。

由于T₁≠T₂，必存在边e=(u,v)属于T₁但不属于T₂。

在T₁中去掉边e，T₁被分成两个连通分量，对应顶点集的一个划分(S, V-S)，其中u∈S，v∈V-S。边e是T₁中唯一跨越该割的边。

由于T₂也是生成树（连通所有顶点），T₂中u到v之间必有路径，该路径必须跨越割(S, V-S)至少一次。因此T₂中至少存在一条跨越该割的边f=(x,y)，且f≠e（因为e∉T₂）。

证明w(e) < w(f)：因为T₁是MST，而e是T₁中唯一跨割的边。若存在某条跨割边g满足w(g) < w(e)，则在T₁中用g替换e得到T₁'=T₁-e+g，T₁'仍是生成树，且权值和为W-w(e)+w(g)<W，与T₁是MST矛盾。因此e是跨割边中权值最小的。又因为各边权值互不相同，e是唯一最小跨割边，故w(e) < w(f)。

在T₂中用e替换f，得到T₂'=T₂-f+e。由于e和f都跨越割(S, V-S)，替换后图仍然连通，且T₂'有n-1条边，是一棵生成树。其权值和为W-w(f)+w(e) < W（因为w(e)<w(f)）。

这与T₂是最小生成树（权值和为W）矛盾。因此假设不成立，G的最小生成树唯一。 ∎

三、模拟训练题

【模拟2-1】如果图中存在权值相同的边，最小生成树是否一定不唯一？举例说明。

【参考答案】

不一定。存在权值相同的边只是MST可能不唯一的必要条件而非充分条件。例如三角形三边权值分别为1、2、2，MST选择权值1和其中一条权值2的边，有两种选择，MST不唯一。但如果相同权值的边在算法执行中不会导致不同的选择（如同权边不在同一候选位置），MST仍可能唯一。

【参考答案】

由大题2的结论，各边权值互异时MST唯一。Kruskal算法和Prim算法都是正确的MST算法，它们得到的生成树都是MST。既然MST唯一，两棵算法得到的MST必然是同一棵树，因此选入的边集合完全相同。

【模拟2-3】叙述割性质，并说明为什么各边权值互异时割性质中的最小边一定在MST中。

【参考答案】

割性质：对任意割(S,V-S)，跨越该割的权值最小边e一定在某棵MST中。证明：任取一棵MST即T，若e∈T则结论成立；若e∉T，将e加入T形成环，环上必有另一条跨割边f，w(e)<w(f)（权值互异），用e替换f得到权值更小的生成树，与T是MST矛盾，故e必在T中。

大题3 AOE网络关键路径计算（15分）

一、知识点讲解

说明：回忆中提到“AOV图，计算各节点EET与ELT，计算各活动ES和LS”。严格来说，EET/ELT（事件最早/最迟发生时间）和ES/LS（活动最早/最迟开始时间）是AOE网（Activity On Edge，边表示活动）中的概念；AOV网（Activity On Vertex，顶点表示活动）主要用于拓扑排序。考试实际考查的是AOE网的关键路径计算，此处按AOE网讲解。

1. AOV网与AOE网的区别

AOV网 AOE网
顶点含义 活动（Activity） 事件（Event）
边含义 活动之间的先后关系（无权值） 活动（有权值，表示持续时间）
主要用途 拓扑排序、判断有无回路 关键路径分析、工期估算
入度/出度为0的点 开始/结束活动 源点（起点）/汇点（终点）

2. 四个关键时间量

符号 名称 含义
ve(j) / EET 事件最早发生时间 从源点到顶点j的最长路径长度，表示事件j最早何时发生
vl(j) / ELT 事件最迟发生时间 在不推迟整个工期的前提下，事件j最迟必须发生的时间
e(i) / ES 活动最早开始时间 活动a_i=<u,v>最早何时开始，等于起点事件的ve(u)
l(i) / LS 活动最迟开始时间 在不推迟工期的前提下，活动a_i最迟何时开始，等于vl(v)-w(u,v)

3. 递推公式

设活动a_i由边<u, v>表示，权值为w(u,v)：

ve(源点) = 0
ve(v) = max{ ve(u) + w(u,v) } 对所有指向v的边<u,v> （按拓扑序正向递推）

vl(汇点) = ve(汇点)
vl(u) = min{ vl(v) - w(u,v) } 对所有从u出发的边<u,v> （按逆拓扑序反向递推）

e(<u,v>) = ve(u)
l(<u,v>) = vl(v) - w(u,v)

时间余量（松弛时间）= l(i) - e(i)
关键活动：l(i) = e(i)（时间余量为0）
关键路径：从源点到汇点由关键活动组成的路径（最长路径）

4. 计算步骤总结

  1. 对AOE网进行拓扑排序，得到顶点的拓扑序列。
  2. 按拓扑序正向递推，计算每个事件的ve（最早发生时间）。
  3. 按逆拓扑序反向递推，计算每个事件的vl（最迟发生时间）。
  4. 对每条活动（边）计算e和l，e=ve(起点)，l=vl(终点)-权值。
  5. 找出所有e=l的活动（关键活动），由关键活动组成的从源点到汇点的路径即关键路径。

**【易错提示】**关键路径是AOE网中从源点到汇点的最长路径，其长度就是整个工程的最短工期。关键活动不允许延误，否则整个工期延长。一个AOE网可能有多条关键路径。

大题4 二级页表地址翻译计算（15分）

一、知识点讲解

1. 分页存储管理基本概念

分页存储管理将进程的逻辑地址空间分成若干大小相等的页（页面），将物理内存分成同样大小的页框（帧）。通过页表建立逻辑页号到物理页框号的映射。

逻辑地址 = 页号 + 页内偏移。若页面大小为2^k B，则页内偏移占k位，其余高位为页号。

2. 一级页表的问题

在32位系统中，若页面大小为4KB（2^12），则页号占20位，每个进程的页表有2^20≈100万个页表项。若每个页表项占4B，则一个进程的页表需要4MB连续内存。这带来两个问题：页表占用大量连续内存；进程并不使用全部地址空间，但页表仍需为所有页建立映射，浪费严重。

3. 二级页表的结构

二级页表将页号再分为两部分：页目录索引（PDE索引）+ 页表索引（PTE索引）。地址结构为：

| 页目录索引（PDE） | 页表索引（PTE） | 页内偏移 |
|<- 外层页号 ->|<- 内层页号 ->|<- 页内 ->|

页目录（外层页表）每个项指向一个页表（内层页表），页表中每个项指向物理页框。只有实际使用的页表才需要创建，实现了页表的离散分配，节省内存。

4. 地址翻译过程

  1. 由虚拟地址的页目录索引查页目录表（页目录基址由页目录基址寄存器给出），得到对应页表的物理基址。
  2. 由页表索引查该页表，得到物理页框号。
  3. 将物理页框号与页内偏移拼接，得到物理地址。

页内偏移位数k k = log₂(页面大小)
虚页号位数 虚拟地址总位数 - k
页表项数/页目录项数 页面大小 / 页表项大小 = 2^m，则索引占m位
页目录索引位数 外层页号位数（由页目录项数决定）
页表索引位数 内层页号位数（由每个页表的项数决定）
虚拟地址空间大小 2^虚拟地址位数
物理地址 （页框号 << k）

**【易错提示】**32位地址 + 4KB页面 + 4B页表项是最经典的考题：页内偏移12位；每页可放4KB/4B=1024=2^10个页表项，故页表索引10位；剩余32-12-10=10位为页目录索引。即10+10+12结构。

二、真题回忆与解析

【题4】（15分）某32位系统采用二级页表进行分页存储管理，页面大小为4KB，每个页表项大小为4B。页目录索引和页表索引各占10位，页内偏移占12位。请回答以下问题：

（1）该系统的虚拟地址空间大小是多少？

（2）页目录表共有多少个表项？每个页目录表和每个页表各占多少字节？

（3）虚拟地址 0x00403001 的页目录索引、页表索引和页内偏移分别是多少（用十进制表示）？

（4）若该地址对应的页表项中物理页框号为 0x12345，则对应的物理地址是多少（用十六进制表示）？

解答：

（1）虚拟地址空间大小

32位虚拟地址 → 2^32 B = 4GB。

（2）页目录/页表项数与大小

页目录索引占10位 → 页目录表项数 = 2^10 = 1024个。

页表索引占10位 → 每个页表有 2^10 = 1024个页表项。

每个页目录表大小 = 1024 × 4B = 4096B = 4KB（恰好占一页）。

每个页表大小 = 1024 × 4B = 4096B = 4KB（也恰好占一页）。

（3）地址分解

将虚拟地址 0x00403001 转为二进制：

0x00403001 = 0000 0000 0100 0000 0011 0000 0000 0001

按 [10位][10位][12位] 划分：
页目录索引 = 0000000001 = 1
页表索引 = 0000000011 = 3
页内偏移 = 000000000001 = 1

验证：0x00403001 = 4206593（十进制）。4206593 / 4096 = 1027（虚页号），1027 = 1×1024 + 3，即页目录索引1、页表索引3；4206593 mod 4096 = 1（偏移）。结果一致。

因此：页目录索引=1，页表索引=3，页内偏移=1。

（4）物理地址计算

物理页框号 = 0x12345，页内偏移 = 1。物理地址 = 页框号 × 页面大小 + 偏移：

物理地址 = (0x12345 << 12) | 0x1
= 0x12345000 | 0x1
= 0x12345001

对应的物理地址为 0x12345001。

三、模拟训练题

【模拟4-1】某32位系统页面大小为8KB，页表项大小为4B。采用二级页表时，页内偏移、页表索引、页目录索引各占多少位？

【参考答案】

页面8KB=2^13 → 页内偏移13位。每页可放页表项数=8KB/4B=2048=2^11 → 页表索引11位。页目录索引=32-13-11=8位。即8+11+13结构。

【模拟4-2】在题4的系统中（4KB页面，10+10+12结构），若虚拟地址为0x00804ABC，请计算页目录索引、页表索引和页内偏移。

【参考答案】

0x00804ABC = 0000 0000 1000 0000 0100 1010 1011 1100。页目录索引(高10位)=0000000010=2；页表索引(中10位)=0000000100=4？重新分组：

二进制：00 0000 0010 | 00 0000 0100 | 1010 1011 1100。页目录索引=0000000010=2；页表索引=0000000100=4；偏移=0xABC=2748。验证：0x804ABC=8407740，8407740/4096=2052余2748，2052=2×1024+4。正确。

【模拟4-3】为什么二级页表可以节省内存？在什么情况下二级页表反而可能比一级页表占用更多内存？

【参考答案】

二级页表中，页目录始终存在，但内层页表只在进程实际使用对应地址范围时才需要创建，不需要的页表不分配内存，因此对于稀疏使用地址空间的进程可以大幅节省内存。但如果进程使用了全部虚拟地址空间（所有页表都被创建），则二级页表除了所有页表外还需要一个页目录，总占用比一级页表多一个页目录的大小（4KB）。

【模拟4-4】某系统虚拟地址32位，页面大小4KB，页表项4B。若采用一级页表，一个进程的页表最多占多少内存？采用二级页表后，若进程只使用了从0开始的1MB地址空间，页表实际占多少内存？

【参考答案】

一级页表：2^20个页表项×4B=4MB。二级页表：1MB/4KB=256页，需要1个页目录(4KB)+1个页表(4KB)=8KB（256个页表项在同一个页表中，因为一个页表覆盖1024×4KB=4MB范围）。
