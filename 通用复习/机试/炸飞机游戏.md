## 第四题：算法——炸飞机游戏（40分）

### 题目描述

在 m 行 × n 列的矩阵方格中随机摆放 k 架飞机，互相不得重叠、交叉。每架飞机形状固定，占 9 格（翼展 5 格、尾翼 3 格、头尾 4 格），有四种方向。输出摆放 k 架飞机的所有可能排列总数（轴对称、对角线对称均重复计数）。

**输入：** m、n、k（4 ≤ m,n ≤ 11，1 ≤ k ≤ min(m,n)）。
**输出：** 一个整数，表示排列总数。

### 飞机形状

以机翼中心为参考点，朝上方向：

```text
..*..
*****
.***.
```

- 机头：1 格（机翼正上方）
- 机翼：5 格（水平翼展）
- 尾翼：3 格（水平尾翼）
- 共 9 格，四种方向通过 90° 旋转得到。

### 思路

DFS 回溯 + 64 位整数位掩码优化：

1. 预处理所有合法飞机位置，编码为两个 `unsigned long long` 位掩码（121 格分 bits 0-63 和 64-120）；
2. 预计算兼容列表 `compat[i]`：所有与飞机 i 不重叠的后续飞机 j；
3. DFS 按索引递增选择飞机（避免重复计数同一组排列），用位掩码快速判断重叠；
4. 剪枝：剩余空格数 \< 剩余飞机数 × 9 时提前回溯。

### 参考代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

int m, n, k;
int P;
vector<unsigned long long> pm_lo, pm_hi;
vector<vector<int>> compat;
long long ans = 0;

// 飞机形状（朝上，以机翼中心为原点）
int shape[9][2] = {
    {-1, 0},
    {0, -2}, {0, -1}, {0, 0}, {0, 1}, {0, 2},
    {1, -1}, {1, 0}, {1, 1}
};

void rotate(int& dr, int& dc) {
    int ndr = dc, ndc = -dr;
    dr = ndr; dc = ndc;
}

void dfs(int placed, int last, unsigned long long lo, unsigned long long hi) {
    if (placed == k) { ans++; return; }
    int occ = __builtin_popcountll(lo) + __builtin_popcountll(hi);
    if (m * n - occ < (k - placed) * 9) return;

    const vector<int>& cand = (placed == 0) ? compat[P] : compat[last];
    for (int j : cand) {
        if ((lo & pm_lo[j]) == 0 && (hi & pm_hi[j]) == 0) {
            dfs(placed + 1, j, lo | pm_lo[j], hi | pm_hi[j]);
        }
    }
}

int main() {
    cin >> m >> n >> k;

    for (int r = 0; r < m; r++) {
        for (int c = 0; c < n; c++) {
            int off[9][2];
            for (int i = 0; i < 9; i++) {
                off[i][0] = shape[i][0];
                off[i][1] = shape[i][1];
            }
            for (int dir = 0; dir < 4; dir++) {
                unsigned long long lo = 0, hi = 0;
                bool valid = true;
                for (int i = 0; i < 9; i++) {
                    int nr = r + off[i][0];
                    int nc = c + off[i][1];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) {
                        valid = false; break;
                    }
                    int bit = nr * n + nc;
                    if (bit < 64) lo |= (1ULL << bit);
                    else hi |= (1ULL << (bit - 64));
                }
                if (valid) {
                    pm_lo.push_back(lo);
                    pm_hi.push_back(hi);
                }
                if (dir < 3)
                    for (int i = 0; i < 9; i++) rotate(off[i][0], off[i][1]);
            }
        }
    }
    P = (int)pm_lo.size();

    compat.resize(P + 1);
    for (int i = 0; i < P; i++) {
        for (int j = i + 1; j < P; j++) {
            if ((pm_lo[i] & pm_lo[j]) == 0 && (pm_hi[i] & pm_hi[j]) == 0) {
                compat[i].push_back(j);
            }
        }
    }
    for (int i = 0; i < P; i++) compat[P].push_back(i);

    dfs(0, P, 0, 0);
    cout << ans << endl;
    return 0;
}
```

### 考点

- DFS 回溯与剪枝；
- 位掩码优化（64 位整数表示棋盘状态）；
- 预计算兼容列表减少重复判断；
- 坐标旋转（90° clockwise：`(dr,dc) → (dc,-dr)`）；
- 组合去重（按索引递增选择，避免同一组排列被重复计数）。
