P2 包裹转运的最大总计费重量

一家快递公司要把一批包裹（用整数表示重量）装进若干辆卡车，每辆卡车最多可以装 k 个连续顺序到达的包裹。装车完成后，每辆卡车的计费重量按该车所装包裹中的最重包裹计算，并按这个重量乘以包裹数收取费用。

为了让公司利润最大化，你需要帮他们决定如何把包裹分配到各辆卡车上（每辆车装的包裹必须是连续的，且不超过 k 个），使得所有卡车的计费重量总和最大。

请写出程序，计算出在最优分配下，公司能够获得的最大总计费重量。

输入格式

  • 第一行是一个整数 n 和一个整数 k，表示数组的长度和 k。
  • 第二行包含 n 个数字，空格隔开，表示数组内容。

输出格式

  • 输出一个整数，表示最大总计费重量。

输入输出样例

样例1

输入：

7 3
1 15 7 9 2 5 10

输出：

84

解释：

  • 数组变为 [15,15,15,9,10,10,10]

题解

动态规划。dp[i] 表示前 i 个包裹的最大总计费重量。枚举最后一辆卡车装载的区间 [j, i-1]（长度不超过 k），在枚举时维护区间最大值：

dp[i] = max{ dp[j] + max(a[j..i-1]) × (i-j) } ，j ∈ [i-k, i-1]

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    vector<long long> dp(n + 1, 0);

    for (int i = 1; i <= n; i++) {
        long long mx = 0;
        for (int j = i - 1; j >= max(0, i - k); j--) {
            mx = max(mx, a[j]);
            dp[i] = max(dp[i], dp[j] + mx * (long long)(i - j));
        }
    }

    cout << dp[n] << '\n';
    return 0;
}
  • 时间复杂度 O(nk)，空间复杂度 O(n)
  • 注意用 long long 防止乘积溢出
