## 2022年机考真题

### 第一题：合法的括号字符串判断（LeetCode 20 同类型）

**题目描述：**

给定一个仅由三种括号组成的字符串 `s`，包含 `(`、`)`、`[`、`]`、`{`、`}`，判断该字符串是否是合法的括号字符串。合法需满足：

1. 左括号必须用相同类型的右括号闭合；
2. 左括号必须以正确的顺序闭合；
3. 空字符串视为合法。

**示例：**

| 输入 | 输出 | 解释 |
| --- | --- | --- |
| `()[]{}` | `true` | 所有括号正确闭合 |
| `(]` | `false` | 括号类型不匹配 |
| `([)]` | `false` | 闭合顺序错误 |
| `{[]}` | `true` | 嵌套顺序正确 |

**思路：** 栈。遇到左括号入栈，遇到右括号检查栈顶是否匹配。最后栈为空则合法。

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool isValid(const string& s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else {
            if (st.empty()) return false;
            char top = st.top();
            st.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                return false;
            }
        }
    }
    return st.empty();
}

int main() {
    string s;
    cin >> s;
    cout << (isValid(s) ? "true" : "false") << endl;
    return 0;
}
```

**复杂度：** 时间 O(n)，空间 O(n)。

### 第二题：最长合法括号子串（LeetCode 32）

**题目描述：**

给定一个仅由 `(` 和 `)` 组成的字符串 `s`，找出其中最长的格式正确且连续的括号子串的长度。

**示例：**

- 输入：`s = "(()"` → 输出：`2`（最长子串为 `"()"`）
- 输入：`s = ")()())"` → 输出：`4`（最长子串为 `"()()"`）

**约束：** `0 <= s.length <= 3e4`，`s[i]` 仅为 `'('` 或 `')'`。

**思路：** 栈存下标，栈底维护最后一个未匹配右括号的位置（初始为 -1）。

```cpp
#include <iostream>
#include <stack>
#include <string>
#include <algorithm>
using namespace std;

int longestValidParentheses(const string& s) {
    stack<int> st;
    st.push(-1);  // 栈底：最后一个未匹配右括号的位置
    int maxLen = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] == '(') {
            st.push(i);
        } else {
            st.pop();
            if (st.empty()) {
                st.push(i);  // 当前右括号无法匹配，作为新的分界
            } else {
                maxLen = max(maxLen, i - st.top());
            }
        }
    }
    return maxLen;
}

int main() {
    string s;
    cin >> s;
    cout << longestValidParentheses(s) << endl;
    return 0;
}
```

**复杂度：** 时间 O(n)，空间 O(n)。

### 第三题：最少插入次数构造回文串（LeetCode 1312）

**题目描述：**

输入一个仅由小写字母组成的字符串 `s`（长度 ≤ 1000），输出使其成为回文串所需的最少插入次数。

**示例：**

- 输入：`s = "abcea"` → 输出：`2`（插入 e 和 b 得到 `"abeceba"`）
- 输入：`s = "aba"` → 输出：`0`（本身已是回文串）

**思路：** 最少插入次数 = 字符串长度 − 最长回文子序列（LPS）长度。LPS 可通过 LCS(s, reverse(s)) 求。

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

int minInsertions(const string& s) {
    int n = s.size();
    string r(s.rbegin(), s.rend());
    // dp[i][j] = s[0..i-1] 与 r[0..j-1] 的 LCS 长度
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (s[i - 1] == r[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return n - dp[n][n];
}

int main() {
    string s;
    cin >> s;
    cout << minInsertions(s) << endl;
    return 0;
}
```

**复杂度：** 时间 O(n²)，空间 O(n²)（可滚动数组优化到 O(n)）。
