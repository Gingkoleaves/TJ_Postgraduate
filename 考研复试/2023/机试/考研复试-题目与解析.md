## 2023年机考真题

### 第一题：签到输出题

**题目描述：**

键盘依次输入 4 个字符串，分别是临时学号、姓名、报考类别和本科学校。按右对齐方式输出，要求其中最长的字符串（标签）输出时左边无空格，4 行的冒号对齐，冒号为半角字符，前后各一个空格。

**输入要求：** 四个字符串均不含空格，长度不超过 40，不考虑输入错误。

**输出要求：** 共四行，不要有多余空行，每行最后无多余空格。

**思路：** 标签右对齐到最长标签宽度（4个汉字=8字节/4显示宽度），后接 `" : "` 和值。

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string labels[] = {"临时学号", "姓名", "报考类别", "本科学校"};
    string values[4];
    for (int i = 0; i < 4; i++) {
        cin >> values[i];
    }
    // 计算最长标签的显示宽度（GBK下汉字算2，ASCII算1）
    int maxWidth = 0;
    int widths[4];
    for (int i = 0; i < 4; i++) {
        int w = 0;
        for (char c : labels[i]) {
            w += ((unsigned char)c > 127) ? 2 : 1;
        }
        // GBK汉字占2字节，每2字节算1个显示宽度
        widths[i] = (int)labels[i].size() / 2;  // 全中文标签，按字数算
        maxWidth = max(maxWidth, widths[i]);
    }
    for (int i = 0; i < 4; i++) {
        for (int j = 0; j < maxWidth - widths[i]; j++) {
            cout << " ";
        }
        cout << labels[i] << " : " << values[i] << endl;
    }
    return 0;
}
```

**输出示例：**

```text
临时学号 : 2023001
    姓名 : 张三
报考类别 : 学硕
本科学校 : 某某大学
```

### 第二题：文件处理

**题目描述：**

用 `main` 函数带参数方式传入一个文件名，打开 a 文件，将 a 文件中的大写字母输出到 b 文件。

**输入要求：**

1. 文件名以 main 函数带参数方式给出（不考虑文件名输入错误）；
2. 文件中字符均为基本 ASCII 码（不含扩展 ASCII/中文）；
3. 文件大小不大于 1GB。

**思路：** `argc/argv` 接收文件名，逐字符读取，判断大写字母（`'A'~'Z'`）写入 `b.txt`。大文件用 `get` 逐字符处理避免内存问题。

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main(int argc, char* argv[]) {
    if (argc < 2) {
        cerr << "Usage: " << argv[0] << " <input_file>" << endl;
        return 1;
    }
    ifstream fin(argv[1], ios::in | ios::binary);
    if (!fin) {
        cerr << "Cannot open file: " << argv[1] << endl;
        return 1;
    }
    ofstream fout("b.txt", ios::out | ios::binary);
    char ch;
    while (fin.get(ch)) {
        if (ch >= 'A' && ch <= 'Z') {
            fout.put(ch);
        }
    }
    fin.close();
    fout.close();
    return 0;
}
```

**Dev-C++ 调试方法：** 菜单"运行"→"参数"中设置 main 函数的参数（填入输入文件路径）。

### 第三题：炸飞机游戏

**题目描述：**

在 m 行 × n 列的矩阵方格中随机摆放 k 架飞机，互相不得重叠、交叉。每架飞机形状固定，占 9 格（翼展 5 格、尾翼 3 格、头尾 4 格），有四种方向。输出摆放 k 架飞机的所有可能排列总数（轴对称、对角线对称均重复计数）。

**输入：** m、n、k 三个整数（4 ≤ m,n ≤ 11，1 ≤ k ≤ min(m,n)）。
**输出：** 一个整数，表示排列总数。

**飞机形状（以机翼中心为参考点，朝上）：**

```text
..*..
*****
.***.
```

共 9 格。四种方向通过旋转得到。

**思路：** DFS 回溯 + 位掩码优化。预处理所有合法飞机位置为两个 64 位整数位掩码（121 格），预计算每架飞机的兼容列表（不重叠的后续飞机），DFS 按索引递增选择避免重复计数，并用剩余格子数剪枝。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int m, n, k;
int P;  // 合法飞机位置总数
vector<unsigned long long> pm_lo, pm_hi;  // 位掩码（bits 0-63 / 64-120）
vector<vector<int>> compat;  // compat[i] = 所有 j>i 且与飞机 i 不重叠的飞机
long long ans = 0;

// 飞机形状（朝上，以机翼中心为原点）
// 头: (-1,0), 机翼: (0,-2)~(0,2), 尾: (1,-1)~(1,1)
int shape[9][2] = {
    {-1, 0},
    {0, -2}, {0, -1}, {0, 0}, {0, 1}, {0, 2},
    {1, -1}, {1, 0}, {1, 1}
};

void rotate(int& dr, int& dc) {
    int ndr = dc, ndc = -dr;
    dr = ndr; dc = ndc;
}

void dfs(int placed, int last, unsigned long long lo, unsigned long long hi) {
    if (placed == k) { ans++; return; }
    // 剪枝：剩余空格不够放剩下的飞机
    int occ = __builtin_popcountll(lo) + __builtin_popcountll(hi);
    if (m * n - occ < (k - placed) * 9) return;
    // placed==0 时从 compat[P]（全部飞机）中选，否则从 compat[last] 中选
    const vector<int>& cand = (placed == 0) ? compat[P] : compat[last];
    for (int j : cand) {
        if ((lo & pm_lo[j]) == 0 && (hi & pm_hi[j]) == 0) {
            dfs(placed + 1, j, lo | pm_lo[j], hi | pm_hi[j]);
        }
    }
}

int main() {
    cin >> m >> n >> k;

    // 预处理：枚举所有位置和方向的飞机
    for (int r = 0; r < m; r++) {
        for (int c = 0; c < n; c++) {
            int off[9][2];
            for (int i = 0; i < 9; i++) {
                off[i][0] = shape[i][0];
                off[i][1] = shape[i][1];
            }
            for (int dir = 0; dir < 4; dir++) {
                unsigned long long lo = 0, hi = 0;
                bool valid = true;
                for (int i = 0; i < 9; i++) {
                    int nr = r + off[i][0];
                    int nc = c + off[i][1];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) {
                        valid = false; break;
                    }
                    int bit = nr * n + nc;
                    if (bit < 64) lo |= (1ULL << bit);
                    else hi |= (1ULL << (bit - 64));
                }
                if (valid) {
                    pm_lo.push_back(lo);
                    pm_hi.push_back(hi);
                }
                if (dir < 3)
                    for (int i = 0; i < 9; i++) rotate(off[i][0], off[i][1]);
            }
        }
    }
    P = (int)pm_lo.size();

    // 预计算兼容列表
    compat.resize(P + 1);
    for (int i = 0; i < P; i++) {
        for (int j = i + 1; j < P; j++) {
            if ((pm_lo[i] & pm_lo[j]) == 0 && (pm_hi[i] & pm_hi[j]) == 0) {
                compat[i].push_back(j);
            }
        }
    }
    for (int i = 0; i < P; i++) compat[P].push_back(i);

    dfs(0, P, 0, 0);
    cout << ans << endl;
    return 0;
}
```

**性能：** 11×11 网格、k=9 时约 3.8 秒（-O2），满足 15 秒时限。

**复杂度分析：** 设合法位置数 P（11×11 时 P=252），DFS 深度 k。兼容列表 + 位掩码运算 + 剩余格子剪枝使实际搜索量远小于 C(P,k)。
