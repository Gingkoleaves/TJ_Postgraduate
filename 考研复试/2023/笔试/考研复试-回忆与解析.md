## 一、专业课部分

### 1. 超市管理数据库（10 分）

在超市管理的简化应用中，有三个实体集：超市、产品、仓库。

- 超市：超市编号、超市名字、超市地址、电话、经理；
- 产品：产品编号、产品名字、价格、生产商、生产日期；
- 仓库：仓库编号、仓库名称、仓库地址、管理员。

超市和产品通过二元关系集“销售”相关，产品和仓库通过二元关系集“库存”相关。

- 销售属性：销售日期、销售数量；
- 库存属性：入库时间、进价、库存数量。

要求：

a. 给出相应的 ER 图；

b. 创建相应的关系模式，并指出主键和外键；

c. 查询销售价格在 100 至 500 元之间、仓库库存少于 20 件的超市名称和数量。

#### 解答

#### a. ER 图

![原文图片](<https://cdn.nlark.com/yuque/0/2026/png/27371136/1787895427157-9a4ea96a-376a-485c-b0fc-d87a49e027c4.png>)

“销售”和“库存”均为多对多关系；若业务规定同一超市同一产品每天只有一条销售记录，可用 `(supermarket_id, product_id, sale_date)` 作销售主键。库存若允许同一产品多次入库，则把 `stock_in_time` 纳入主键。

#### b. 关系模式

```text
Supermarket(
    supermarket_id PK,
    name, address, phone, manager
)

Product(
    product_id PK,
    name, price, manufacturer, production_date
)

Warehouse(
    warehouse_id PK,
    name, address, manager
)

Sales(
    supermarket_id FK -> Supermarket(supermarket_id),
    product_id FK -> Product(product_id),
    sale_date,
    sale_quantity,
    PK(supermarket_id, product_id, sale_date)
)

Inventory(
    product_id FK -> Product(product_id),
    warehouse_id FK -> Warehouse(warehouse_id),
    stock_in_time,
    purchase_price,
    stock_quantity,
    PK(product_id, warehouse_id, stock_in_time)
)
```

#### c. SQL

若“数量”指满足条件的销售数量总和，可写为：

```text
SELECT s.name,
       SUM(sa.sale_quantity) AS quantity
FROM Supermarket AS s
JOIN Sales AS sa
  ON sa.supermarket_id = s.supermarket_id
JOIN Product AS p
  ON p.product_id = sa.product_id
JOIN Inventory AS i
  ON i.product_id = p.product_id
WHERE p.price BETWEEN 100 AND 500
  AND i.stock_quantity < 20
GROUP BY s.supermarket_id, s.name;
```

如果题意中的“数量”是每条销售记录的数量而非汇总，去掉 `SUM` 和 `GROUP BY`，直接选择 `sa.sale_quantity` 即可。若一个产品在多个仓库均满足库存条件，为避免重复计数，可将库存条件改成 `EXISTS` 子查询。

### 2. 函数依赖与 3NF（10 分）

关系 `R(A,B,C,D,E,F)` 满足：

```text
F = { ABD -> E, AB -> CF, B -> F, C -> DF, CF -> E, D -> F }
```

#### (1) 求 `(BC)+`、`(AB)+`

先将右部拆成单属性：

```text
ABD -> E, AB -> C, AB -> F, B -> F,
C -> D, C -> F, CF -> E, D -> F
```

- `(BC)+`：初始 `{B,C}`；由 `C -> D,F` 得到 `D,F`；由 `CF -> E` 得到 `E`。因此

```text
(BC)+ = {B,C,D,E,F}
```

- `(AB)+`：由 `AB -> C,F` 得到 `C,F`；由 `C -> D` 得到 `D`；由 `CF -> E` 得到 `E`。因此

```text
(AB)+ = {A,B,C,D,E,F}
```

`AB` 是该关系的候选码。

#### (2) 正则覆盖（最小覆盖）

去除冗余后可取：

```text
Fc = { AB -> C, B -> F, C -> D, C -> E, D -> F }
```

说明：`AB -> F` 可由 `B -> F` 推出；`C -> F` 可由 `C -> D`、`D -> F` 推出；`CF -> E` 中的 `F` 是左部冗余，可改为 `C -> E`；`ABD -> E` 可由 `AB -> C`、`C -> E` 推出。

#### (3) 无损且保持依赖的 3NF 分解

按正则覆盖综合：

```text
R1(A,B,C)   // 对应 AB -> C
R2(B,F)     // 对应 B -> F
R3(C,D,E)   // 对应 C -> D、C -> E
R4(D,F)     // 对应 D -> F
```

`R1` 含候选码 `AB`，因此综合算法保证无损连接；每条最小覆盖中的函数依赖都在某个分解关系中得到保持。

### 3. 句子、句型、短语的定义（6 分）

- **句子（sentence）**：由一个或多个单词按语法规则组成、能够表达相对完整意义的语言单位。
- **句型（sentence pattern）**：句子的结构类型或抽象语法模板，例如 `S -> NP VP`，它描述成分及其组合关系，而不是某个具体句子。
- **短语（phrase）**：句型或句子中由一个语法单位派生出的连续符号串；在编译原理中，若 `S =>* αAγ` 且 `A =>+ β`，则 `β` 是句型 `αβγ` 的一个短语。

### 4. 正则表达式转 NFA、确定化与最小化（8 分）

正则表达式：

```text
(b | c)(a | b)*ac
```

#### NFA

可使用以下等价 NFA（无需 ε 边）：

```text
q0 --b,c--> q1
q1 --a,b--> q1
q1 --a--> q2
q2 --c--> q3   (q3 为终态)
```

其中从 `q1` 读入 `a` 时可以同时走循环边或走向 `q2`，体现 `(a|b)*` 后接 `ac` 的非确定性。

#### 子集构造得到 DFA

令 `D = ∅` 为死状态，`S0={q0}`、`S1={q1}`、`S2={q1,q2}`、`S3={q3}`：

| DFA 状态 | a | b | c | 是否终态 |
| --- | --- | --- | --- | --- |
| `S0={q0}` | `D` | `S1` | `S1` | 否 |
| `S1={q1}` | `S2` | `S1` | `D` | 否 |
| `S2={q1,q2}` | `S2` | `S1` | `S3` | 否 |
| `S3={q3}` | `D` | `D` | `D` | 是 |
| `D=∅` | `D` | `D` | `D` | 否 |

#### 最小化

初始划分为 `{S3}` 与 `{S0,S1,S2,D}`。按转移到终态/非终态及后续分区继续细分后，五个状态均不可合并，因此上表 DFA 已是最小 DFA。

### 5. 基本块目标代码、RVALUE 与 AVALUE（6 分）

中间代码：

```text
1. T := A - B
2. U := A - C
3. V := T + U
4. W := V + U
```

已知基本块出口处 `W` 活跃，只有 `R0`、`R1` 可用。一个无冗余存取的目标代码为：

```text
LD  R0, A       ; R0 = A
SUB R0, B       ; R0 = T = A-B
LD  R1, A       ; R1 = A
SUB R1, C       ; R1 = U = A-C
ADD R0, R1      ; R0 = V = T+U
ADD R0, R1      ; R0 = W = V+U
ST  W, R0       ; W 在出口处活跃，写回内存
```

以下只列出关键变化（内存中的原变量仍保留其原地址）：

| 时刻 | `RVALUE(R0)` | `RVALUE(R1)` | 主要 AVALUE |
| --- | --- | --- | --- |
| 初始 | `{}` | `{}` | `A:{A}, B:{B}, C:{C}` |
| `LD R0,A` 后 | `{A}` | `{}` | `A:{A,R0}` |
| `SUB R0,B` 后 | `{T}` | `{}` | `T:{R0}`，`A:{A}` |
| `LD R1,A` 后 | `{T}` | `{A}` | `A:{A,R1}`，`T:{R0}` |
| `SUB R1,C` 后 | `{T}` | `{U}` | `T:{R0}`，`U:{R1}` |
| `ADD R0,R1` 后 | `{V}` | `{U}` | `V:{R0}`，`U:{R1}` |
| `ADD R0,R1` 后 | `{W}` | `{U}`（已死） | `W:{R0}` |
| `ST W,R0` 后 | `{W}` | `{U}`（已死） | `W:{W,R0}` |

`T`、`V` 和 `U` 在基本块出口不活跃，因此不必额外写回；`W` 必须写回。

### 6. 第 k 大的数（10 分）

#### a. 每次找最大值并删除

若数组未排序，每次线性扫描找最大值需要 `O(n)`，删除后规模递减，总时间：

```text
O(n + (n-1) + ... + (n-k+1)) = O(kn)
```

若数组删除还需搬移元素，仍为 `O(kn)`；辅助空间为 `O(1)`（忽略输入存储）。

#### b. 排序后取第 k 大

用比较排序将数组按升序排列，返回下标 `n-k` 的元素：时间 `O(n log n)`，空间取决于排序实现（原地快排平均 `O(log n)`，归并排序 `O(n)`）。

#### 自行设计：大小为 k 的最小堆

维护当前见过元素中最大的 `k` 个数，堆顶就是第 `k` 大：

```text
KthLargest(A, k):
    H = empty min-heap
    for x in A:
        if size(H) < k:
            push(H, x)
        else if x > min(H):
            pop_min(H)
            push(H, x)
    return min(H)
```

建堆阶段可视为逐个插入，时间 `O(n log k)`，空间 `O(k)`。当 `k` 很小，该方法优于完整排序；也可使用 Quickselect，平均 `O(n)`、最坏 `O(n^2)`，用 median-of-medians 选枢轴可保证最坏 `O(n)`。

### 7. 有距离约束的最大收益（10 分）

街上有按位置递增排列的 `n` 个位置，位置 `i` 的收益为 `p[i]`，任意两家店距离必须大于 `d`，求最大总收益。

令

```text
prev[i] = max { j < i | position[i] - position[j] > d }
```

不存在时令 `prev[i]=0`。设 `DP[i]` 为只考虑前 `i` 个位置的最大收益，则：

```text
DP[0] = 0
DP[i] = max(DP[i-1], p[i] + DP[prev[i]])
```

伪代码：

```text
MaxProfit(position[1..n], p[1..n], d):
    for i = 1..n:
        prev[i] = binary_search_last_j(
            position[j] <= position[i] - d - epsilon)
    DP[0] = 0
    for i = 1..n:
        DP[i] = max(DP[i-1], p[i] + DP[prev[i]])
    return DP[n]
```

若位置为整数且“距离大于 `d`”等价于 `position[j] <= position[i]-d-1`，将 `epsilon` 换成 `1`。二分查找每个 `prev[i]` 得 `O(n log n)` 时间，DP 为 `O(n)`，总空间 `O(n)`；位置已经排序时用双指针可把前驱查找降为 `O(n)`。

### 阅读材料转录：*Artificial Intelligence & Creativity: A Manifesto for Collaboration*

Creativity is a phenomenon that is not unique to the human species, as it can be considered to be the guiding force in the evolution of our entire universe. In the dynamic universal creativity process, a potential for creative emergence can be recognized in four layers: material, biological, socio-cultural, and artificial. Creativity episodes occurring at different layers of complexity are possibly concatenated: this manifesto is specifically concerned with the interconnections between human-centered socio-cultural creativity and machine-centered artificial creativity.

Interest in the field of AI has recently grown with the arrival of tools like ChatGPT and Midjourney, as well as Microsoft Bing and Google Bard. Reflections on artificial agents are much older, however, and include myths such as Talos and the Golem. Ada Lovelace even anticipated that a machine might compose elaborate music. In 1956 John McCarthy introduced the term AI; AI systems are distinguished by their ability to adapt and use information beyond a fixed sequence of programmed instructions.

Generative AI (GAI) uses existing information to create new content. This capability affects creative occupations. Studies cited in the paper report that ChatGPT made college-educated professionals faster and improved the quality of their writing, while GitHub Copilot made professional programmers substantially faster without a statistically significant quality improvement. Other analyses suggest that telemarketing, legal services, financial investment, and insurance may be especially exposed. At the same time, plagiarism, factual errors, and fabricated references remain important weaknesses.

The paper asks whether GAI is truly creative. AI-generated content is new in a practical sense, but it is built from pre-existing data, just as much human creativity builds on prior experience. GAI performs well on routine, patterned content, yet it is less reliable on disruptive and highly personal creative work. Humans contribute long-term motivation, curiosity, experience, and a personal point of view. The notion of creative intentionality is therefore central and remains debated.

The manifesto advocates human-AI collaboration. AI can generate many candidate ideas during the “blind variation” stage of the Campbell-Simonton BVSR model. Humans should define and refine the problem at the beginning, then select, evaluate, modify, and validate outputs at the end. This is “assisted creativity”: AI is a collaborative creative agent, while human judgment remains essential.

### 参考作答：Brief summary

The manifesto argues that generative AI should be understood as a partner in human creativity rather than as an independent artist. AI systems can produce many plausible ideas quickly and can improve productivity in writing and programming. Nevertheless, their novelty is often limited by the structure of their training data, and they remain vulnerable to factual errors, plagiarism, and fabricated references. Human creators contribute intention, curiosity, experience, and the ability to pursue disruptive personal visions. The authors therefore propose a division of labor based on the BVSR model: AI performs large-scale blind variation, while humans define the problem, select promising results, revise them, and take final responsibility. The future is best described as assisted creativity, supported by careful human oversight.

### 参考作答：Short research proposal

**Title: Human-in-the-Loop Evaluation of AI-Assisted Creativity**

**Background and objectives.** Generative AI can produce many ideas in seconds, but speed does not necessarily imply originality, usefulness, or responsible authorship. This project will investigate when AI assistance improves creative performance and when it causes homogenization, factual errors, or over-reliance. It will focus on the interaction between human problem finding, AI idea generation, and human selection.

**Research questions.** (1) Does AI increase the novelty and usefulness of solutions compared with unaided work? (2) Does requiring users to write a problem definition before prompting improve final quality? (3) How do expertise and the number of generated candidates affect human selection? (4) Can provenance and fact-checking tools reduce errors without reducing creative value?

**Method.** We will recruit participants from design, writing, and software backgrounds. They will complete matched tasks under three conditions: no AI, AI brainstorming only, and AI brainstorming plus structured human review. Outputs will be evaluated blindly by independent experts using novelty, usefulness, coherence, and factuality scales. We will record time, revision history, prompt logs, and participants’ confidence. A mixed-effects model will test the effects of condition and expertise; qualitative interviews will examine perceived agency and authorship.

**Expected contribution and ethics.** The study should identify practical collaboration protocols that preserve human agency while exploiting AI’s breadth. All participants will provide informed consent, generated material will be checked for sensitive or copyrighted content, and results will report both benefits and failure cases. The outcome will be an evidence-based framework for responsible assisted creativity.
