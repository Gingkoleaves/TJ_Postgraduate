## P3 到达首都的最少油耗

给你一棵 n + 1 个节点的树（一个无向、连通、无环图），每个节点表示一个城市，编号从 0 到 n，且恰好有 n 条路。0 是首都。给你一个二维整数数组 roads，其中 roads\[i\] = \[ai, bi\]，表示城市 ai 和 bi 之间有一条双向路。

每个城市里有一个代表，他们都要去首都参加一个会议。

每座城市里有一辆车。给你一个整数 seats 表示每辆车里面座位的数目。

城市里的代表可以选择乘坐所在城市的车，或者乘坐其他城市的车。相邻城市之间一辆车的油耗是一升汽油。

请你返回到达首都最少需要多少升汽油。

**输入格式**

- 第一行是一个整数 n 和座位数 seats，n 表示 roads 的大小。
- 接下来 n 行每行两个数字以空格分隔，表示 roads

**输出格式**

- 输出一个整数，表示到达首都最少需要多少升汽油。

**输入输出样例**

样例1

输入：

```text
3 5
0 1
0 2
0 3
```

输出：

```text
3
```

### 题解

树形DFS + 贪心。从叶子向根统计每个子树需要运送的代表人数，每条边需要的车数为 ⌈人数 / seats⌉，每辆车经过该边耗油1升，累加所有边的车数即可。

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> adj;
int seats;
long long ans = 0;

// 返回以 u 为根的子树中的代表总人数
int dfs(int u, int parent) {
    int people = 1; // 本市的1名代表
    for (int v : adj[u]) {
        if (v == parent) continue;
        int child = dfs(v, u);
        people += child;
        // 子树 child 人经过边 u-v，需要 ceil(child/seats) 辆车，耗油即车数
        ans += (child + seats - 1) / seats;
    }
    return people;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n >> seats;
    adj.assign(n + 1, {});

    for (int i = 0; i < n; i++) {
        int a, b;
        cin >> a >> b;
        adj[a].push_back(b);
        adj[b].push_back(a);
    }

    dfs(0, -1);
    cout << ans << '\n';
    return 0;
}
```

- 时间复杂度 O(n)，空间复杂度 O(n)
