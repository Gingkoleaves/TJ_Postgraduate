## 第一题：签到题（10分）

### 题目描述

键盘依次输入 4 个字符串，分别是临时学号、姓名、报考类别和本科学校，按**右对齐**方式输出。要求其中最长的字符串（标签）输出时左边无空格，4 行的冒号对齐，冒号为半角字符，前后各一个空格。

**输入要求：**

1. 四个字符串均不含空格，长度不超过 40；
2. 不考虑输入错误。

**输出要求：**

1. 共四行，不要有多余的空行；
2. 每行最后无多余的空格或其它字符。

### 思路

标签右对齐到最长标签的显示宽度，后接 `" : "` 和输入的值。中文标签在 GBK 编码下每个汉字占 2 字节、显示宽度为 2 个字符。本题标签固定为"临时学号""姓名""报考类别""本科学校"，最长为 4 个汉字（显示宽度 4），"姓名"为 2 个汉字，需前补 2 个空格。

### 参考代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string labels[] = {"临时学号", "姓名", "报考类别", "本科学校"};
    string values[4];
    for (int i = 0; i < 4; i++) {
        cin >> values[i];
    }
    // 标签均为中文，按字数计算显示宽度（每字宽度2）
    int widths[] = {8, 4, 8, 8};  // 字节数：4字=8, 2字=4
    int maxWidth = 8;             // 最长标签"临时学号/报考类别/本科学校"=4字=8字节
    for (int i = 0; i < 4; i++) {
        // 前导空格补齐到最长宽度
        for (int j = widths[i]; j < maxWidth; j += 2) {
            cout << "  ";  // 一个汉字宽度 = 2个空格
        }
        cout << labels[i] << " : " << values[i] << endl;
    }
    return 0;
}
```

### 输出示例

```text
临时学号 : 2020001
    姓名 : 张三
报考类别 : 学硕
本科学校 : 某某大学
```

> **注意：** 本题与 2023 年机考第一题完全相同，是同济的经典签到题。

## 第二题：递归（20分）

### 题目描述

1. 键盘输入 2-9 间的数字，输出对应的数字三角形；
2. **采用递归方式完成，整个程序中不允许出现循环**（for、while、do-while、if-goto 均不允许）；
3. 给出预置的 cpp 文件，其中 main 函数不允许改动。

**输入要求：** 输入一个 2-9 间的整数，不考虑输入错误。

**输出要求：**

1. 若输入的数字是 n，则共输出 n 行；
2. 每个数字之间加一个空格，每行的最后一个 1 后面，既可以有空格，也可以无空格。

### 输出样例

输入 `4`，输出：

```text
1
2 1
3 2 1
4 3 2 1
```

### 思路

题目要求纯递归、禁止一切循环。需要两个递归函数：

- `printRow(row)`：递归打印第 row 行，从 row 倒数到 1；
- `printTriangle(cur, n)`：递归打印第 1 行到第 n 行。

每行以 1 结尾（题目说"每行的最后一个1后面"），所以第 i 行输出 `i, i-1, ..., 2, 1`。

### 参考代码

```cpp
#include <iostream>
using namespace std;

// 递归打印一行：从 n 倒数到 1
void printRow(int n) {
    if (n == 0) return;       // 递归终止
    cout << n;
    if (n > 1) cout << " ";   // 数字之间加空格，最后一个1后不加
    printRow(n - 1);
}

// 递归打印 n 行三角形
void printTriangle(int cur, int n) {
    if (cur > n) return;      // 递归终止
    printRow(cur);
    cout << endl;
    printTriangle(cur + 1, n);
}

int main() {
    int n;
    cin >> n;
    printTriangle(1, n);
    return 0;
}
```

### 输入 `9` 的输出

```text
1
2 1
3 2 1
4 3 2 1
5 4 3 2 1
6 5 4 3 2 1
7 6 5 4 3 2 1
8 7 6 5 4 3 2 1
9 8 7 6 5 4 3 2 1
```

### 考点

- 递归思维：用递归替代循环，注意终止条件；
- 两个递归函数的配合：一个控制行，一个控制行内数字；
- 空格处理：数字之间加空格，行末不留多余空格（题目允许行末有空格，但规范写法不留）。

## 第三题：文件处理（30分）

### 题目描述

用 main 函数带参数方式传入一个文件名，打开该文件，统计文件中出现的**大写字母、小写字母、数字、空格及其它字符**的个数，并输出五种类型字符的总数。

**注：** other 的计数方法，不允许取文件大小后减去其余四种，必须是判断该字符的值不属于前 4 种后再归入 other 计数。

**输入要求：**

1. 文件名以 main 函数带参数方式给出（不考虑文件名输入错误）；
2. 假设文件中字符均为基本 ASCII 码（不含扩展 ASCII/中文）；
3. 文件大小不大于 1GB；
4. Dev-C++ 中菜单"运行"-"参数"可设置 main 函数参数。

**输出要求：**

1. 共六行，不要有多余的空行；
2. 每行最后无多余的空格或其它不可见字符；
3. 前五行的值之和应等于第六行，第六行的值应与文件属性中显示的字节大小一致。

### 思路

- 使用 `int main(int argc, char* argv[])` 接收文件名参数；
- 逐字符读取文件（`fin.get(ch)`），按 ASCII 范围分类计数；
- 大写 `'A'~'Z'`、小写 `'a'~'z'`、数字 `'0'~'9'`、空格 `' '`，其余归入 other；
- 用二进制模式打开（`ios::binary`）确保 `\r\n` 在 Windows 下被分别计数（`\r` 计入 other），使总数等于文件字节大小；
- 逐字符处理，内存占用 O(1)，可处理 1GB 大文件。

### 参考代码

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main(int argc, char* argv[]) {
    if (argc < 2) {
        cerr << "Usage: " << argv[0] << " <filename>" << endl;
        return 1;
    }

    ifstream fin(argv[1], ios::in | ios::binary);
    if (!fin) {
        cerr << "Cannot open file: " << argv[1] << endl;
        return 1;
    }

    int upper = 0, lower = 0, digit = 0, space = 0, other = 0;
    char ch;

    while (fin.get(ch)) {
        if (ch >= 'A' && ch <= 'Z') {
            upper++;
        } else if (ch >= 'a' && ch <= 'z') {
            lower++;
        } else if (ch >= '0' && ch <= '9') {
            digit++;
        } else if (ch == ' ') {
            space++;
        } else {
            other++;  // 必须逐个判断归入，不能用文件大小减去
        }
    }
    fin.close();

    int total = upper + lower + digit + space + other;

    cout << "upper: " << upper << endl;
    cout << "lower: " << lower << endl;
    cout << "digit: " << digit << endl;
    cout << "space: " << space << endl;
    cout << "other: " << other << endl;
    cout << "total: " << total << endl;

    return 0;
}
```

### 输出示例（假设参数为 helloworld.cpp）

```text
upper: 5
lower: 120
digit: 8
space: 42
other: 35
total: 210
```

> 实际数值取决于文件内容。`total` 应等于文件的字节大小。

### 考点与注意事项

- **main 函数参数**：`argc` 是参数个数，`argv[1]` 是文件名；
- **大文件处理**：逐字符读取而非一次性读入内存，1GB 文件也无内存压力；
- **二进制模式**：Windows 下文本模式会将 `\r\n` 转换为 `\n`，导致计数少一个字节，必须用 `ios::binary`；
- **other 计数方式**：题目明确要求逐个字符判断，不能用 `文件大小 - 前四种`；
- Dev-C++ 调试时在"运行→参数"中填入文件路径。
