机试一共包括4题，使用cpp/c，可用万能头；空间限制128MB，时间限制1s

1，输入5个[0,9999]的数，打印如下：
=================================
0         1         2         3
0123456789012345678901234567890123456789
=================================
0         0         0          1
0         0         0           2
0         0         0            3
0         0         0             4
0         0         0              5
=================================
标尺已经给出，一共有0-3四组，每组0-9，中间5行是你的程序输出，每行除了数字外，用空格填充，最后一个数后无空格

2，输入n，输入n个十进制正整数a0~an-1，输入基数b[2,9]，求这n个数的各位累加和中能被基数整除的数的个数；其中，n[1,1000],ai[1,INT_MAX]
示例：n=7，b=3
输入：7 23 7 37505416 87 12 9 17 3
输出：4
解释：2+3=5,7,3+7+5+0+5+4+1+6=31,8+7=15,1+2=3,9,1+7=8,3，其中能被基数3整除的有15,3,9,3共4个数

3，给定正整数n[1,31],求长度为n的序列在二分时各索引被访问的顺序，按照格式化输出
示例：n=6
输入：6
输出：[不提供标尺]
==================
 0  1  2  3  4  5 
==================

       1
 2     1     2
 2  3  1  3  2  3 
==================
 其中，标尺的长度是3*n，每个数字的宽度是3,0-9居中，10-31左对齐

4，给定一个长为n的序列a1-an，定义一次操作为ai=ai+a(i mod n +1)。给出m个请求，问第x次操作后ay的值；在运算过程中，如果ai>998244353，则对998244353取模；其中，n[2,100]，m[1,100]，ai[1,2^31 -1]，x[1,2000]，y[1,n]
示例：输入n，a1-an，m，x1，y1，x2，y2 ......
输入：5 2 1 4 5 3 2 1 2 2 2 
输出：5 14
解释：序列2 1 4 5 3 ，问经过1次操作后a2的值，经过2次操作后a2的值
