P1 最大威力值计算

在一款文字拼图游戏中，玩家需要从一组英文单词中挑选两张"字母卡片"来组成最强的组合。每张卡片上写着一个单词。组合的"威力值"计算方式是两张卡片上单词长度的乘积。但有一个限制：如果两张卡片上的单词含有相同的字母，就会产生冲突，导致无法组合。

请你编写程序，帮助游戏设计者从给定的单词列表中，找出可以合法组合且威力值最大的两张卡片，并返回这个最大威力值。如果不存在任何符合条件的组合，则返回 0。

输入格式

  • 第一行是一个整数 n，表示 words 的长度。
  • 第二行包含 n 个字符串，空格隔开，表示 words 内容。

输出格式

  • 输出一个整数，表示最大威力值。

输入输出样例

样例1

输入：

6
abcw baz foo bar xtfn abcdef

输出：

16

解释：

  • 这两个单词为 "abcw", "xtfn"

题解

每个单词用一个26位二进制整数表示其包含的字母集合。两个单词不含公共字母等价于它们的掩码按位与为0。枚举所有配对取最大值即可。

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<string> words(n);
    vector<int> mask(n, 0);
    vector<int> len(n, 0);

    for (int i = 0; i < n; i++) {
        cin >> words[i];
        len[i] = (int)words[i].size();
        for (char c : words[i]) {
            mask[i] |= 1 << (c - 'a');
        }
    }

    int ans = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if ((mask[i] & mask[j]) == 0) {
                ans = max(ans, len[i] * len[j]);
            }
        }
    }

    cout << ans << '\n';
    return 0;
}
