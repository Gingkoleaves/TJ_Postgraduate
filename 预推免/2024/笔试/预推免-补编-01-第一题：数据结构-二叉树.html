第一题：数据结构-二叉树

涉及知识点

1. 二叉树的基本概念

  • 定义：每个节点最多有两个子节点的树形数据结构
  • 术语：
    • 根节点、叶子节点、内部节点
    • 深度（从根到节点的边数）
    • 高度（从节点到最深叶子的边数）
    • 层次（根节点为第1层）

2. 二叉树的性质

  • 第 i 层最多有 2^(i-1) 个节点（i≥1）
  • 深度为 k 的二叉树最多有 2^k - 1 个节点
  • 对任何二叉树，若叶子节点数为 n0，度为2的节点数为 n2，则 n0 = n2 + 1

3. 完全二叉树

  • 定义：除最后一层外，其他层节点数达到最大，最后一层节点从左到右连续排列
  • 性质：
    • n个节点的完全二叉树高度为 ⌊log₂n⌋ + 1
    • 可以用数组高效存储（下标从1开始，节点i的左孩子为2i，右孩子为2i+1）

4. 满二叉树

  • 定义：所有层的节点数都达到最大值
  • 深度为k的满二叉树有 2^k - 1 个节点

5. 二叉树的遍历

  • 前序遍历：根-左-右（DLR）
  • 中序遍历：左-根-右（LDR）
  • 后序遍历：左-右-根（LRD）
  • 层序遍历：按层从上到下、从左到右

根据回忆补全的题目

题目：已知一棵完全二叉树有127个节点，求：

  1. 该完全二叉树的高度是多少？
  2. 该完全二叉树的叶子节点有多少个？
  3. 如果对该树进行层序编号（从1开始），编号为50的节点在第几层？其父节点编号是多少？

详细解析

解答1：求高度

  • 完全二叉树节点数 n = 127
  • 高度 h = ⌊log₂127⌋ + 1 = ⌊6.988⌋ + 1 = 6 + 1 = 7

解答2：求叶子节点数

  • 设度为1的节点数为 n1，度为2的节点数为 n2，叶子节点数为 n0
  • 总节点数：n0 + n1 + n2 = 127
  • 根据性质：n0 = n2 + 1
  • 对于完全二叉树，n1 只能是0或1
    • 前6层是满二叉树，共 2^6 - 1 = 63 个节点
    • 第7层有 127 - 63 = 64 个节点
    • 第7层刚好填满一半（该层最多128个），所以第6层所有节点都有左孩子
    • n1 = 0（所有非叶子节点都有两个孩子）
  • 从边数关系：总边数 = n - 1 = 126
    • 也可表示为：0×n0 + 1×n1 + 2×n2 = 126
    • 即：n1 + 2×n2 = 126
    • 由于 n1 = 0，所以 2×n2 = 126，n2 = 63
  • 因此 n0 = n2 + 1 = 64

解答3：求节点50的层次和父节点

  • 节点50所在层次：设为第k层
    • 前k-1层共有 2^(k-1) - 1 个节点
    • 需要满足：2(k-1) - 1 < 50 ≤ 2k - 1
    • k = 6时：25 - 1 = 31 < 50 ≤ 26 - 1 = 63 ✓
    • 所以节点50在第6层
  • 父节点编号 = ⌊50/2⌋ = 25

答案：

  1. 高度为 7
  2. 叶子节点有 64 个
  3. 节点50在第6层，父节点编号为25

模拟练习题

练习1

一棵完全二叉树有511个节点，回答：

  1. 树的高度是多少？
  2. 第8层有多少个节点？
  3. 编号为100的节点的左右孩子编号分别是多少？

点击查看答案

  1. h = ⌊log₂511⌋ + 1 = 8 + 1 = 9 2. 前8层共 2^8 - 1 = 255 个节点，所以第9层有 511 - 255 = 256 个节点 3. 左孩子编号 = 2×100 = 200，右孩子编号 = 2×100 + 1 = 201

练习2

已知一棵二叉树的前序遍历序列为：A B D E C F G，中序遍历序列为：D B E A F C G，请画出该二叉树，并给出后序遍历序列。

点击查看答案

分析过程：- 前序第一个A是根节点 - 在中序中找到A，左边DBE是左子树，右边FCG是右子树 - 左子树：前序BD E，中序D BE → B是根，D是左孩子，E是右孩子 - 右子树：前序C FG，中序FC G → C是根，F是左孩子，G是右孩子 树的结构： A / \ B C / \ / \ D E F G 后序遍历：D E B F G C A

练习3

若一棵完全二叉树有768个节点，其中叶子节点有多少个？

点击查看答案

设 n0（叶子）、n1（度为1）、n2（度为2）- n0 + n1 + n2 = 768 - n0 = n2 + 1 - 完全二叉树 n1 = 0 或 1 判断 n1：- 768 = 2^9 + 2^8 = 512 + 256（恰好填满第10层的一半） - 第9层最后一个节点有两个孩子，所以 n1 = 0 计算：- n1 + 2n2 = 767 - 0 + 2n2 = 767（不是整数，说明 n1 = 1） - 实际上 768 = 2^10 - 256，第10层有256个节点，第9层有一个节点只有左孩子 - 1 + 2n2 = 767，n2 = 383 - n0 = 384 答案：384个叶子节点
