T1：电话号码段与服务匹配判断

题目描述

在服务调度系统中，存在若干个服务，每个服务仅向指定的电话号码段提供（即仅该号码段内的电话号码可使用此服务）。需根据给定的服务 - 号码段绑定关系，以及一组电话号码的服务请求序列，逐一判断每个电话号码是否存在可使用的服务，并输出判断结果。

核心规则说明：

  1. 电话号码固定为 11 位纯数字（如<font style="color:rgb(0, 0, 0);">13812345678</font>），无需处理非 11 位或含非数字的非法号码；
  2. 号码段为电话号码的前缀（如号码段<font style="color:rgb(0, 0, 0);">138</font>对应所有以<font style="color:rgb(0, 0, 0);">138</font>开头的 11 位号码，号码段<font style="color:rgb(0, 0, 0);">138123</font>对应所有以<font style="color:rgb(0, 0, 0);">138123</font>开头的 11 位号码），号码段长度范围为<font style="color:rgb(0, 0, 0);">1~7</font>位（确保前缀匹配逻辑无歧义）；
  3. 一个服务可绑定多个号码段（如 “流量服务 A” 绑定<font style="color:rgb(0, 0, 0);">138</font>、<font style="color:rgb(0, 0, 0);">139</font>两个段），一个号码段仅绑定一个服务（题目保证输入无冲突）；
  4. 若一个电话号码匹配多个服务的号码段（即多个服务的号码段均为该号码的前缀），则视为 “服务可用”，需列出所有匹配的服务；若未匹配任何服务的号码段，则视为 “服务不可用”。

输入说明

输入分为两部分，两部分数据连续输入，格式如下：

第一部分：服务 - 号码段绑定关系

  1. 第 1 行：一个整数<font style="color:rgb(0, 0, 0);">m</font>（<font style="color:rgb(0, 0, 0);">1 ≤ m ≤ 10</font>），表示服务的数量；
  2. 第 2~m+1 行：每行描述一个服务的绑定关系，格式为 <font style="color:rgb(0, 0, 0);">服务名 号码段数量k 号码段1 号码段2 ... 号码段k</font>：
    • 服务名：由字母、数字或下划线组成的字符串（长度<font style="color:rgb(0, 0, 0);">1~20</font>，无空格），如<font style="color:rgb(0, 0, 0);">Flow_Service_1</font>、<font style="color:rgb(0, 0, 0);">Voice_Package</font>；
    • 号码段数量<font style="color:rgb(0, 0, 0);">k</font>：<font style="color:rgb(0, 0, 0);">1 ≤ k ≤ 5</font>，表示当前服务绑定的号码段个数；
    • 号码段：纯数字字符串（长度<font style="color:rgb(0, 0, 0);">1~7</font>），如<font style="color:rgb(0, 0, 0);">138</font>、<font style="color:rgb(0, 0, 0);">159000</font>。

第二部分：服务请求序列

  1. 第 m+2 行：一个整数<font style="color:rgb(0, 0, 0);">n</font>（<font style="color:rgb(0, 0, 0);">1 ≤ n ≤ 100</font>），表示服务请求的数量；
  2. 第 m+3~m+2+n 行：每行一个 11 位纯数字字符串，即待判断的电话号码，如<font style="color:rgb(0, 0, 0);">13812345678</font>、<font style="color:rgb(0, 0, 0);">15998765432</font>。

输入保证：

  • 所有号码段均为合法前缀（无超出 7 位的情况）；
  • 无重复号码段（即同一个号码段不会绑定到多个服务）；
  • 电话号码均为 11 位纯数字，无需处理非法格式。

输出说明

针对第二部分的每个服务请求，输出一行判断结果，格式要求如下：

  1. 若服务可用（匹配到至少一个服务）：
    <font style="color:rgb(0, 0, 0);">电话号码XXX：服务可用（匹配服务：S1,S2,S3）</font>
    • 其中<font style="color:rgb(0, 0, 0);">XXX</font>为输入的 11 位电话号码；
    • <font style="color:rgb(0, 0, 0);">S1,S2,S3</font>为匹配到的所有服务名，按服务在输入中的顺序（即第 2 行服务优先于第 3 行服务） 排列，用英文逗号分隔，无多余空格。
  2. 若服务不可用（未匹配任何服务）：
    <font style="color:rgb(0, 0, 0);">电话号码XXX：服务不可用</font>

输出顺序需与服务请求的输入顺序完全一致。

5

示例解析
  1. 号码<font style="color:rgb(0, 0, 0);">13812345678</font>：
    • 前缀<font style="color:rgb(0, 0, 0);">138</font>匹配<font style="color:rgb(0, 0, 0);">Flow_Service</font>，前缀<font style="color:rgb(0, 0, 0);">138123</font>匹配<font style="color:rgb(0, 0, 0);">Data_Package</font>，故匹配两个服务，按服务输入顺序排列；
  2. 号码<font style="color:rgb(0, 0, 0);">15998765432</font>：前缀<font style="color:rgb(0, 0, 0);">159</font>匹配<font style="color:rgb(0, 0, 0);">Voice_Package</font>，仅一个服务；
  3. 号码<font style="color:rgb(0, 0, 0);">13700000000</font>：无任何服务的号码段为其前缀，服务不可用；
  4. 号码<font style="color:rgb(0, 0, 0);">17711112222</font>：前缀<font style="color:rgb(0, 0, 0);">177</font>匹配<font style="color:rgb(0, 0, 0);">Voice_Package</font>；
  5. 号码<font style="color:rgb(0, 0, 0);">13999998888</font>：前缀<font style="color:rgb(0, 0, 0);">139</font>匹配<font style="color:rgb(0, 0, 0);">Flow_Service</font>。
#include <iostream>
#include <vector>
#include <string>
#include <unordered_set>

using namespace std;

// 服务结构体：存储服务名和对应的号码段
struct Service {
string name;
vector<string> prefixes;
};

int main() {
    int m;
    cin >> m;

    // 存储所有服务
    vector<Service> services;
    for (int i = 0; i < m; ++i) {
        Service s;
        int k;
        cin >> s.name >> k;

        // 读取k个号码段
        for (int j = 0; j < k; ++j) {
            string prefix;
            cin >> prefix;
            s.prefixes.push_back(prefix);
        }

        services.push_back(s);
    }

    // 读取请求数量
    int n;
    cin >> n;

    // 处理每个电话号码请求
    for (int i = 0; i < n; ++i) {
        string phone;
        cin >> phone;

        // 存储匹配的服务名，使用set去重
        unordered_set<string> matchedSet;
        // 存储按顺序的匹配服务名
        vector<string> matchedList;

        // 检查每个服务
        for (const Service& s : services) {
            bool isMatched = false;
            // 检查该服务的所有号码段
            for (const string& prefix : s.prefixes) {
                // 检查前缀是否匹配
                if (phone.substr(0, prefix.length()) == prefix) {
                    isMatched = true;
                    break;
                }
            }

            // 如果匹配且未添加过，则加入结果
            if (isMatched && matchedSet.find(s.name) == matchedSet.end()) {
                matchedSet.insert(s.name);
                matchedList.push_back(s.name);
            }
        }

        // 输出结果
        cout << "电话号码" << phone << "：";
        if (matchedList.empty()) {
            cout << "服务不可用" << endl;
        } else {
            cout << "服务可用（匹配服务：";
            for (int j = 0; j < matchedList.size(); ++j) {
                if (j > 0) {
                    cout << ",";
                }
                cout << matchedList[j];
            }
            cout << "）" << endl;
        }
    }

    return 0;
}

T2：字符串子串的数字频率差值最大值计算

题目描述

:::success
给定一个仅包含数字 <font style="color:rgba(0, 0, 0, 0.85) !important;">0-4</font> 的字符串 <font style="color:rgba(0, 0, 0, 0.85) !important;">s</font>，以及一个正整数 <font style="color:rgba(0, 0, 0, 0.85) !important;">k</font>，需对 <font style="color:rgba(0, 0, 0, 0.85) !important;">s</font> 中所有长度至少为 **<font style="color:rgb(0, 0, 0);">k</font>** 的连续子串（以下简称 “有效子串”）执行以下操作，最终返回所有操作结果中的最大值：

  1. 频率统计：对当前有效子串，统计数字 <font style="color:rgb(0, 0, 0);">0</font>、<font style="color:rgb(0, 0, 0);">1</font>、<font style="color:rgb(0, 0, 0);">2</font>、<font style="color:rgb(0, 0, 0);">3</font>、<font style="color:rgb(0, 0, 0);">4</font> 的出现次数（记为 <font style="color:rgb(0, 0, 0);">freq[x]</font>，<font style="color:rgb(0, 0, 0);">x ∈ {0,1,2,3,4}</font>）；
  2. 筛选与计算：从 <font style="color:rgb(0, 0, 0);">0-4</font> 中选择两个数字 <font style="color:rgb(0, 0, 0);">a</font> 和 <font style="color:rgb(0, 0, 0);">b</font>（<font style="color:rgb(0, 0, 0);">a</font> 与 <font style="color:rgb(0, 0, 0);">b</font> 可相同），满足：
    • <font style="color:rgb(0, 0, 0);">freq[a]</font> 为奇数次（即 <font style="color:rgb(0, 0, 0);">freq[a] % 2 == 1</font>）；
    • <font style="color:rgb(0, 0, 0);">freq[b]</font> 为偶数次（即 <font style="color:rgb(0, 0, 0);">freq[b] % 2 == 0</font>，包括 <font style="color:rgb(0, 0, 0);">freq[b] = 0</font> 的情况）；
    • 计算差值 <font style="color:rgb(0, 0, 0);">diff = freq[a] - freq[b]</font>；
  3. 子串最优值：对当前有效子串，找出所有符合条件的 <font style="color:rgb(0, 0, 0);">diff</font> 中的最大值（若当前子串无符合条件的 <font style="color:rgb(0, 0, 0);">a</font> 和 <font style="color:rgb(0, 0, 0);">b</font> 组合，该子串不贡献结果，视为无效）。

最终结果为所有有效子串的最优值中的最大值；若所有有效子串均无效（无符合条件的 <font style="color:rgba(0, 0, 0, 0.85) !important;">a</font> 和 <font style="color:rgba(0, 0, 0, 0.85) !important;">b</font>），返回 <font style="color:rgba(0, 0, 0, 0.85) !important;">-∞</font>（或根据场景约定返回特定标识，题目保证输入至少存在一个有效结果）。

:::

输入说明

  1. 输入字符串**** **<font style="color:rgb(0, 0, 0);">s</font>**：
    • 仅包含数字 <font style="color:rgb(0, 0, 0);">0-4</font>，无空格、字母或特殊字符；
    • 长度范围：<font style="color:rgb(0, 0, 0);">1 ≤ len(s) ≤ 100</font>（避免极端长串导致计算超时，同时保证暴力枚举子串的可行性）；
  2. 整数**** **<font style="color:rgb(0, 0, 0);">k</font>**：
    • 表示有效子串的最小长度，范围：<font style="color:rgb(0, 0, 0);">1 ≤ k ≤ len(s)</font>（若 <font style="color:rgb(0, 0, 0);">k > len(s)</font>，无有效子串，题目保证 <font style="color:rgb(0, 0, 0);">k ≤ len(s)</font>）；
  3. 输入格式：第一行输入字符串 <font style="color:rgb(0, 0, 0);">s</font>，第二行输入整数 <font style="color:rgb(0, 0, 0);">k</font>。

输出说明

  1. 输出一个整数（或浮点数，若存在小数情况，本题中 <font style="color:rgb(0, 0, 0);">freq</font> 为整数，<font style="color:rgb(0, 0, 0);">diff</font> 必为整数），表示所有有效子串的 <font style="color:rgb(0, 0, 0);">diff</font> 最大值；
  2. 若所有有效子串均无符合条件的 <font style="color:rgb(0, 0, 0);">a</font> 和 <font style="color:rgb(0, 0, 0);">b</font>（题目保证此情况不出现，仅需考虑正常场景），输出 <font style="color:rgb(0, 0, 0);">-∞</font>。

示例

示例 1：基础输入

输入

123
2

输出

1

示例 2

输入

00112
3

输出

1

题解思路

  1. 子串枚举：需遍历所有 “长度 ≥k” 的连续子串，枚举方式为：
    • 外层循环控制子串起始索引 <font style="color:rgb(0, 0, 0);">i</font>（<font style="color:rgb(0, 0, 0);">0 ≤ i < len(s)</font>）；
    • 内层循环控制子串结束索引 <font style="color:rgb(0, 0, 0);">j</font>（<font style="color:rgb(0, 0, 0);">i + k - 1 ≤ j < len(s)</font>），子串为 <font style="color:rgb(0, 0, 0);">s[i..j]</font>（闭区间）；
    • 时间复杂度为 <font style="color:rgb(0, 0, 0);">O(len(s)²)</font>，对 <font style="color:rgb(0, 0, 0);">len(s) ≤ 100</font> 完全适用。
  2. 频率统计优化：
    • 暴力统计：对每个子串 <font style="color:rgb(0, 0, 0);">s[i..j]</font>，遍历 <font style="color:rgb(0, 0, 0);">i</font> 到 <font style="color:rgb(0, 0, 0);">j</font> 统计 <font style="color:rgb(0, 0, 0);">freq[x]</font>，时间复杂度 <font style="color:rgb(0, 0, 0);">O(len(s)³)</font>（可接受）；
    • 前缀和优化：预处理前缀和数组 <font style="color:rgb(0, 0, 0);">prefix[j+1][x]</font>（表示前 <font style="color:rgb(0, 0, 0);">j</font> 个字符中 <font style="color:rgb(0, 0, 0);">x</font> 的出现次数），则子串 <font style="color:rgb(0, 0, 0);">s[i..j]</font> 的 <font style="color:rgb(0, 0, 0);">freq[x] = prefix[j+1][x] - prefix[i][x]</font>，时间复杂度降至 <font style="color:rgb(0, 0, 0);">O(len(s)² × 5)</font>（更高效）。
  3. 奇偶数判断与差值计算：
    • 对每个子串的 <font style="color:rgb(0, 0, 0);">freq[x]</font>，先标记其奇偶性（<font style="color:rgb(0, 0, 0);">is_odd[x] = freq[x] % 2</font>）；
    • 遍历所有 <font style="color:rgb(0, 0, 0);">a</font>（<font style="color:rgb(0, 0, 0);">is_odd[a] = 1</font>）和 <font style="color:rgb(0, 0, 0);">b</font>（<font style="color:rgb(0, 0, 0);">is_odd[b] = 0</font>），计算 <font style="color:rgb(0, 0, 0);">diff = freq[a] - freq[b]</font>，记录最大值；
    • 遍历范围仅 <font style="color:rgb(0, 0, 0);">5×5=25</font> 种组合，开销极小。
  4. 边界处理：
    • 子串长度等于 <font style="color:rgb(0, 0, 0);">k</font> 或大于 <font style="color:rgb(0, 0, 0);">k</font> 的情况需全部覆盖；
    • <font style="color:rgb(0, 0, 0);">b</font> 的 <font style="color:rgb(0, 0, 0);">freq[b] = 0</font> 属于偶次，需纳入考虑（此类情况常贡献高 <font style="color:rgb(0, 0, 0);">diff</font>，如示例 3 中 <font style="color:rgb(0, 0, 0);">b=1</font> 出现 0 次，<font style="color:rgb(0, 0, 0);">diff=3-0=3</font>）。
#include <iostream>
#include <string>
#include <vector>
#include <climits>

using namespace std;

int main() {
    string s;
    int k;
    cin >> s >> k;

    int n = s.length();
    int global_max = INT_MIN;  // 存储全局最大值

    // 枚举所有可能的子串起点
    for (int i = 0; i < n; ++i) {
        int freq[5] = {0};  // 统计0-4的频率

        // 枚举子串终点，扩展子串长度
        for (int j = i; j < n; ++j) {
            // 更新当前字符的频率
            int num = s[j] - '0';
            freq[num]++;

            // 只处理长度至少为k的子串
            if (j - i + 1 >= k) {
                int current_max = INT_MIN;

                // 寻找当前子串的最大有效差值
                // 遍历所有可能的a (出现奇数次)
                for (int a = 0; a < 5; ++a) {
                    if (freq[a] % 2 == 1) {  // a出现奇数次
                        // 遍历所有可能的b (出现偶数次)
                        for (int b = 0; b < 5; ++b) {
                            if (freq[b] % 2 == 0) {  // b出现偶数次
                                int diff = freq[a] - freq[b];
                                if (diff > current_max) {
                                    current_max = diff;
                                }
                            }
                        }
                    }
                }

                // 更新全局最大值
                if (current_max > global_max) {
                    global_max = current_max;
                }
            }
        }
    }

    cout << global_max << endl;

    return 0;
}
